1.4.9 Admin Dashboard (Paneli i Administratorit)

Paneli kryesor i kontrollit të plotë të sistemit, i qasshëm vetëm për rolin "Admin".

 

Komponentët kryesorë:

• User Management: Lista e të gjithë përdoruesve dhe organizatorëve. Mundësia për të bllokuar ose fshirë llogari që thyejnë rregullat.

• Event Approval: Monitorimi i ngjarjeve të krijuara nga organizatorët përpara se ato të shfaqen publike.

• System Logs: Raportet e gabimeve ose anomalive në platformë.

 

Veprimet e mundshme:

• Aprovimi/Refuzimi i ngjarjeve -> Kontrolli i cilësisë së përmbajtjes në platformë.
